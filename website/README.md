# data_dumps website

Modest public landing (plain HTML/CSS, minimal JS for mobile nav). Product
front door: hero → what the app does → outcomes → local-first → install.

- Open `index.html` locally, or deploy via GitHub Pages (`.github/workflows/pages.yml`).
- Logo lives in [images/](images/) (copied from [`assets/logo.png`](../assets/logo.png)).
- Live path: [glenwright.earth/data_dumps](https://glenwright.earth/data_dumps/).
- Footer version should match [pyproject.toml](../pyproject.toml) `version` (currently **0.1.1**).
- No Sphinx guide. Docs stay Markdown in the repo; the landing links to GitHub.
- Ko-fi support link in the footer: https://ko-fi.com/C0C1XK8G
- Umami snippet uses the `data_dumps` website on `analytics.glenwright.earth`. Do not reuse the glenwright.earth site id.
